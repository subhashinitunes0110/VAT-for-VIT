# Adaptive Visual Learning Assistant

An AI-powered adaptive visual learning system that transforms educational content into source-grounded interactive visual explanations.

## Project Focus

The initial prototype focuses on Computer Science concepts.

## Core Idea

Educational Text
        ↓
Semantic Understanding
        ↓
Knowledge Representation
        ↓
Pedagogical Reasoning
        ↓
Visualization Selection
        ↓
Interactive Visual Explanation
        ↓
Learner Feedback
        ↓
Adaptive Re-visualization

## Project Structure

- `backend/` — FastAPI backend and AI pipeline
- `frontend/` — User interface
- `schemas/` — Structured data schemas
- `visualizations/` — Interactive visualizations
- `docs/` — Project documentation
- `experiments/` — Evaluation and experiments
